# Rubii 会话轮数与指令区

桌面 Chrome 扩展，当前版本 **v0.2.0**。支持 macOS 和 Windows 桌面 Chrome；手机版尚未适配。

## 功能

- 统计当前聊天卡的历史会话，包含未手动存档的会话。
- 按 session_id 区分会话，按 round_id 配对和去重统计。
- 顶部显示「和角色名认识已经 XX 天了」，按可读取的最早真实聊天记录计算。
- 本机指令区：新增、编辑、删除、复制和搜索。
- JSON 世界书导入：只保留标题和内容，相同标题与内容不重复导入。

## 下载与安装

[下载 v0.2 安装包](./rubii-round-counter-v0.2.zip)

1. 下载并解压安装包。
2. 电脑 Chrome 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 打开已登录的 Rubii 聊天页，点击插件图标，再打开网站「历史对话」。
5. 点击「统计全部会话」。指令管理在面板「指令区」。

更新时覆盖原先加载的文件夹，在扩展管理页点击刷新，再刷新 Rubii 网页。不必卸载；卸载会清除本地指令。完整步骤见 [使用说明](./使用说明.md)。

## 数据与权限

指令仅保存于当前 Chrome 配置的扩展本地存储，不跨设备同步。无外部服务、遥测或自动发送消息。仓库不含个人世界书、聊天记录或登录凭据。

权限：activeTab、scripting、storage、clipboardWrite。统计向 Rubii 同源已核实的 GET 接口请求数据；临时登录头与聊天数据不持久化。

## 范围与限制

范围是当前聊天卡接口返回的记录，不能视为跨所有聊天卡的角色总数。删除、超长记录截断及复杂分支可能影响结果；异常情况提示待核对。认识日期取消息真实 created_at，不使用剧情正文日期。

已有合成计数、导入、存储、日期逻辑和语法检查；尚未完成全部浏览器端到端及所有分支边界验证。本工具与 Rubii 官方无关联。
